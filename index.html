Principais comandos

🎶 Música

  • !tocar [música] - Toca a música desejada ou adiciona à fila.
  • !pular - Pula para a próxima faixa.
  • !parar - Para a música e limpa a fila atual.
  • !fila - Mostra a lista de reprodução.
  • !remover [número] - Remove uma música específica da fila.
  • !pausar / !retomar - Pausa ou retoma a reprodução.
  • !sair - Desconecta o Larry do canal de voz.
  • !comandos - Lista todas as funções disponíveis.

🤖 IA

Use !larry, !ia ou !chat para perguntar, criar ou pedir sugestões no servidor.

Exemplos rápidos:

!larry qual a cor do céu? !ia crie uma ideia de nick estiloso para o meu time. !chat escreva uma rima engraçada para o servidor.
